# Dọn cache Trivy và kiểm tra cache uv

## Yêu cầu

Linh yêu cầu dọn hai cache đã liệt kê trên `/home`: database Trivy của Deka và cache gói `uv`.
Harness intake 32, lane tiny.

## Quyết định và tệp thay đổi

- Xác thực hệ điều hành để dọn `trivy.db` và `metadata.json` trong cache Trivy do root tạo.
  Kiểm tra đường dẫn thật, danh sách file và kiểu file trước khi xóa.
- Dùng CLI `uv` với `--offline` và giới hạn thời gian chờ. Tiến trình Python con của phiên
  Codex nạp thư viện từ cache nên giữ khóa/các file đang dùng.
- Cập nhật `AI_LOGS/HANDOFF.md`, `AI_LOGS/TASKS.md` và log phiên này.

## Lệnh và kiểm chứng

- `df -B1`, `uv cache dir`, `du`, `ps`, `lsof`: xác nhận hai cache trên `/home` và khóa `uv`.
- Qua `pkexec`, gỡ hai file đúng thư mục database Trivy. Thư mục đã trống. Dung lượng khả dụng
  tăng thêm 1.625.337.856 B trong lúc dọn Trivy, `/home` sau thao tác còn khoảng 5,69 GB.
- `uv cache clean --offline` và `uv cache prune --offline` báo cache đang được dùng và chờ khóa
  tới khi hết thời gian. Cache `uv` còn khoảng 1,1 GiB.
- Import thư viện trong hai môi trường Python của API và Discord bot thành công. API health và
  frontend `/graph` trả 200. `git diff --check` và kiểm Markdown đạt.

## Vấn đề còn lại và bước kế tiếp

Dọn `uv` khi tiến trình `uv` và Python con của phiên Codex đã đóng cache. Trivy sẽ tải lại cơ
sở dữ liệu lỗ hổng ở lần quét tiếp theo.
