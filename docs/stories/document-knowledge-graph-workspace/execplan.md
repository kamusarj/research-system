# Exec Plan

## Goal

Within the owner-specified maximum of eight hours, complete the document-scoped graph analysis,
independent AI comparison, governed promotion, relationship/hierarchy parity and separate system
map as one verified vertical slice.

## Scope

In scope:

- Automatic isolated graph for every readable supported upload.
- 150–200 character node summaries and AI research comparison.
- Selected/all-node AI research plus draft change-set creation.
- View analysis entry and complete document graph inspector.
- Remove the 100-item relationship display cap while retaining a 1,000-node safety bound.
- Derive hierarchy from the approved relationship corpus.
- Separate Business AI Agents system map.
- Backend, frontend, runtime and Harness proof.

Out of scope:

- Direct AI apply/publication.
- Autonomous general web crawler.
- Unlimited/unbounded graph API responses.
- Neo4j ownership or a new graph database migration.

## Risk Classification

Risk flags:

- Data model.
- External systems.
- Public contracts.
- Existing behavior.
- Multi-domain.

Hard gates:

- External provider behavior.

## Work Phases

1. Inspect existing document processing, graph projections and user entry points.
2. Record the durable graph ownership/promotion decision and acceptance contract.
3. Implement provider/schema/service/API behavior with deterministic tests.
4. Implement document analysis, global graph parity and separate system-map UI.
5. Run focused and full validation, rebuild the local stack and perform browser/runtime proof.
6. Complete Harness trace, story proof and AI handoff logs.

## Stop Conditions

Pause for human confirmation if:

- The requested behavior would require direct AI publication or deletion.
- A destructive data migration becomes necessary.
- Existing graph review validation would need to be weakened.
- The eight-hour bound cannot be met without materially narrowing acceptance criteria.
