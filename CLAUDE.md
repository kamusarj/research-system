# Claude Code Instructions

Follow the repository-wide agent instructions in `AGENTS.md`.

Mandatory workflow:

1. Read `AI_LOGS/HANDOFF.md`.
2. Read `AI_LOGS/TASKS.md`.
3. Read `AI_LOGS/DECISIONS.md` if the task touches architecture, product scope, data model, or workflow.
4. Do the requested work.
5. Before stopping, update `AI_LOGS/HANDOFF.md`, `AI_LOGS/TASKS.md`, and create a session log in `AI_LOGS/SESSIONS/`.

Never write secrets, API keys, credentials, customer PII, or sensitive business data into `AI_LOGS/`.
